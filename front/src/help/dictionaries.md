# Справочники

Справочники — это то, чем вы оперируете в операциях: кому заплатили, из какой кассы, за что. Их восемь видов.

| Справочник | Для чего |
|---|---|
| Контрагент | Клиенты и поставщики |
| Касса/Счёт | Расчётные счета, кассы, карты |
| Статья ДДС | Куда движутся деньги: поступление от клиентов, аренда, налоги |
| Статья дохода | Из чего складывается выручка |
| Статья расхода | На что тратим |
| Номенклатура | Товары и услуги |
| Сотрудник | Для расчётов с персоналом |
| Склад/Отдел | Разрез по подразделениям |

## Заполнение по шаблону

При создании компании справочники **пустые**, и это сделано намеренно: набор статей зависит от вида деятельности, и «универсальный» список всё равно переделывают под себя.

Нажмите «Заполнить по шаблону», выберите ближайший к вашему делу и дальше правьте руками. Это быстрее, чем заводить сорок статей с нуля, и честнее, чем работать по чужому списку.

## Иерархия

Элементы вкладываются друг в друга: «Расходы на команду» → «Зарплата», «Обучение». В отчётах это даёт свёртку — родитель показывает сумму всех своих потомков, а раскрыв его, видно из чего она.

Глубина не ограничена, но три уровня обычно достаточно: на четвёртом отчёт перестаёт читаться.

## ИНН у контрагента

Заполненный ИНН — не формальность. По нему банковская выписка сама находит контрагента в вашем справочнике, и вручную подставлять его не приходится. Если ИНН не заполнен, поиск идёт по названию, а названия в выписке приходят в самом разном виде.

## Удаление

Элемент, на который уже ссылаются операции, не удаляется — иначе в отчётах появились бы суммы без имени. Такой элемент можно переименовать или сделать неактивным: он исчезнет из выпадающих списков, но останется в прошлых операциях.
